# FeedShield Known Gaps & Stub Registry

In strict adherence to **CLAUDE.md Section 0.3 Rule 5 (No fake functionality)**, this registry tracks any feature that is simulated, interface-only, or currently in progress.

---

## Active Registry

| Feature | Classification | Honesty Label in UI | Documented Limitation / Next Step |
|---|---|---|---|
| **Physical NIR Spectrometer** | Simulated Hardware | **SIMULATED** | Physical benchtop spectrometer (e.g. NeoSpectra/NIRScan) is simulated using chemometric physical equations (`data_provenance: synthetic_demo`). Web Bluetooth protocol is implemented but marked untested with physical hardware. |
| **Physical pH & Temp Probes** | Simulated Hardware | **SIMULATED** | Virtual probe driver produces realistic values with sensor drift and temp compensation. Digital manual entry is always available and tagged `USER-ENTERED`. |
| **Silage Pit Telemetry (IoT)** | Simulated Sensor | **SIMULATED** | Real-time pit trend data is generated by `tools/iot_sim/` across 3 physiological profiles (Healthy, Aerobic Heating, Fermentation Failure). |
| **Nutrition Prediction (Protein/Fiber)** | Synthetic Demo Model | **DEMO** | Trained on 1,200 physically plausible synthetic spectra. High CV accuracy reflects synthetic physics, not field calibration against Indian cattle feeds. Model card carries mandatory synthetic banner. |
| **Visible Mould Estimation** | Classical CV Heuristic | **ESTIMATED** | Color-space segmentation and local entropy analysis. Does not claim CNN detection or mycotoxin/aflatoxin quantification. |
| **Urea Adulteration** | Colorimetric Screening | **SCREENING** | Qualitative screening class based on colorimetric strip reading. UI explicitly warns: *"Urea cannot be assessed from this image alone. Confirmatory laboratory test recommended."* |
| **Regional Languages (Beyond en, hi, hinglish)** | Architectural Stub | **FUTURE LOCALE** | Locale file structure and translation key mapping is implemented; machine translation pending linguistic field verification. |
